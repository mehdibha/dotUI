# Fixture Prose Only

## 1. Visual Theme & Atmosphere

A calm, paper-like interface with one green accent.

## 2. Color Palette & Roles

- **Cream** (`#f7f4ed`): Page background, the default canvas.
- **Forest** (`#2f6b4f`): Primary actions and links.
- **Charcoal** (`#2b2a27`): Body text.
- **Stone** (`#8a857b`): Muted text.

## 3. Typography Rules

**Primary**: `Inter`
**Display**: `Playfair Display`
**Mono**: `JetBrains Mono`

## 4. Elevation

Cards rest on a subtle drop shadow.
