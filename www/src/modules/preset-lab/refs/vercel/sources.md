# Vercel: sources

Geist publishes its tokens on [vercel.com/geist/colors](https://vercel.com/geist/colors) (the scales), [vercel.com/geist/materials](https://vercel.com/geist/materials) (radii and shadows per surface) and [vercel.com/geist/typography](https://vercel.com/geist/typography) (the `text-heading-*` / `text-copy-*` / `text-button-*` classes). The docs showcases render the same components as the dashboard, so the pack measures them.

## 2026-10-21

`tokens.json` comes from `presets:measure --pack vercel`: the public Geist docs pages in `targets.json`, headless at 1440×900, light and dark through `prefers-color-scheme`. Re-measured the same day on probe 8eb9b12, which added the radio, segmented, progress, alert, field label, icon button and field focus parts. Reference screenshots, crops and compare sheets are in the project files under `presets/vercel/2026-10-21/`. The signed-in dashboard was measured the same day (see below).

- **Theme variables** (`--ds-*`, read off `:root`):
  - Neutrals: background-100 `#fff` / `#0a0a0a` (cards, fields, menus, dialogs), background-200 `#fafafa` / `#000` (the page), gray-100 `#f2f2f2` / `#1a1a1a`, gray-alpha-400 `#00000014` / `#ffffff24` (every hairline), gray-700 `#8f8f8f` (check edges, placeholders), gray-900 `#4d4d4d` / `#a1a1a1` (muted text), gray-1000 `#171717` / `#ededed` (ink). Field values use `--geist-foreground`, pure `#000` / `#fff`.
  - Accent: blue-700 `#0072f5` in both modes for fills (switch, slider, choice cards); focus and links use `--ds-focus-color`, which is blue-700 in light and blue-900 `#52a8ff` in dark.
  - Status: red-800 `#da2f35`, amber-800 `#ff990a`. Success notes and toasts are blue, not green.
  - Focus: `--ds-focus-ring` is a 2px background ring inside a 4px focus-color ring, which the probe reads as `2px` at `+2px`. Fields use `--ds-focus-border`: a 1px edge at 34% black plus a 4px halo at 16% (51% and 24% white in dark), which the probe reads as the edge plus `3px` at `+1px`.
  - Shadows: `--ds-shadow-menu`, `-modal` and `-tooltip` all start with the gray-alpha-400 1px ring, then small soft drops; menus and cards add a background-200 1px ring under it, so their edge shows a step darker than a bare hairline.
- **Materials page**: base radius 6px (`--geist-radius`), menus and modals 12px, tooltips 6px, fullscreen 16px.
- **Parts and how they are read**:
  - `button.*` come from the size row of /geist/button (`:nth-child` picks primary, secondary, tertiary); `button.focus` tabs to the primary. The docs show icon-only buttons only as primaries, so `button.icon` reads just the 36px square's radius and height.
  - `input` and `input.focus` read `[data-geist-input-wrapper]`, which draws the edge and the focus border, with `ink` on the input. The covering input computes 0px corners and the wrapper no padding, so `borderRadius` and `paddingInline` are left out. `field.label` is the 13px label above a field.
  - `checkbox`, `radio` and the `switch.*` track are the drawn boxes after their hidden inputs; `checkbox.checked` clicks a label first. `segmented.*` are the first Geist Switch (Source / Output) on /geist/switch: its unselected item is clear, so its `borderRadius` is left out.
  - `tab.selected` leaves out `edge`: Geist draws a 2px bottom border on the tab itself, dotUI a separate indicator. Clear tabs leave out `borderRadius`.
  - `button.quiet`, the tabs and `alert` (the default Note) are clear and sit on the docs' example cards (background-100), not the page, so their `backgroundColor` is left out.
  - `menu`, `menu.item` and `command.*` open the first demo on their page; `tooltip` hovers the first legacy tooltip trigger. That tooltip draws 8px corners while the Materials page specifies 6px, and wraps to two lines, so its `borderRadius` and `height` are left out. `text.muted` is the modal subtitle.
  - `progress` is the default bar (10px, 6px corners). Its fill is a `::-webkit-progress-value` the probe can't read, so `progress.fill` is entered by hand from the bar's classes: gray-1000 with 6px corners.
  - `badge` is gray-subtle on /geist/badge (the second badge: gray-200 under ink) and `badge.accent` blue-subtle (the fourth: a blue tint under blue text, `#0068d6` / `#52a8ff`), the style every badge in the dashboard wears (see 2026-10-22); the solid gray (`#4d4d4d` under white) and blue (blue-800 `#0062d1`) ones lead the docs page but don't appear in the product. `card` is `.material-base` on /geist/materials, which sets no text color, so `color` is left out. Headings are the `text-heading-40/32/24/20` rows of /geist/typography, with `fontSize` and `letterSpacing` left out on the first two (the specimens set 36px and 30px); `text` is `text-copy-16`, which takes the docs' color.
  - Some docs elements set the `GeistSans` alias, the same font as `Geist`: `fonts` maps it.
- **Signed-in dashboard** (`vercel.com/dashboard`, `signedIn`): measured in Chrome with the `--snippet` at 1512×743, light and dark by setting Vercel's `zeit-theme` key (restored after), then `--merge`d per mode. Only computed styles were read, no workspace content.
  - `page` is the body; `shell` the fixed sidebar container; `panel` the content section beside it (`<main>` wraps the sidebar too). All three share one fill, background-200 `#fafafa` / `#000`. The 256px sidebar is set apart by a 1px gray-200 rule (`#ebebeb` / `#1f1f1f`) on its right, which no part reads. A 56px sticky top bar holds the breadcrumbs.
  - `nav.item` and `nav.item.active` are the sidebar links (`data-sidebar-link-key`, current by `data-active`): 36px rows, 6px corners, 14/400, resting in gray-900 and current in gray-1000 on gray-200 (`#ebebeb` / `#1f1f1f`). Each row starts with a 36px icon box 2px in and puts the label 38px in, so `paddingInline` is left out.
- **Wide pass** (same day): every /geist page (78) and the main vercel.com pages (home, pricing, docs, templates, changelog, blog, login, signup, enterprise, sales, font), full page in both modes, plus the overlays the pack doesn't open (sheet, context menu, combobox, multi-select, split button, dots menu, destructive modal, toast, filter params, select, the mobile drawer). Screenshots and a per-page style census are in the project files under `presets/vercel/2026-10-21/explore/public/`. Cross-checks, not in `tokens.json`:
  - /geist/sheet is the side drawer: docked and square, 384px, background-100 inside the gray-alpha-400 ring with the modal shadow, 24px padding, an 18/600 title over 14px gray-900 text, the page under a `#f2f2f2` wash in light.
  - Prose links on vercel.com/docs are ink at 500, always underlined in 34% black (51% white in dark); pricing and changelog links stay 400. That's the docs site's own prose style: the dashboard's links are blue (see 2026-10-22).
  - The census agrees with the pack: 6px is by far the most common radius, text is 14/20 at 400 in gray-900 and gray-1000, headings run 24/32 at -0.96px, 20/26 at -0.4px and 40/48 at -2.4px, hairlines are gray-alpha-400.
- **Not in the pack**: drawer (Geist's is a mobile bottom sheet), calendar (/geist/calendar still fails to load headless on the wide pass), toggle buttons and pagination numbers (Geist has neither).

## 2026-10-22

Mehdi captured the signed-in dashboard in his own Chrome (a local session driving it over CDP, 1440×900 at 2x): 15 pages, light and dark through `prefers-color-scheme` (`zeit-theme` was unset, so nothing to restore). Only computed styles and UI chrome were kept; the full-page shots show account content and stay private in the project files under `presets/vercel/2026-10-22/signed-in/`, next to the raw readings and the cropped components. Pages: overview, a project, its deployments, a deployment, logs, observability, storage, domains, usage, team settings, members, project settings, environment variables, account, integrations.

- **`link`** comes from the environment variables page (`signedIn`; `<team>/<project>` stand for any project): the description's "Learn more" link, `--merge`d per mode. Dashboard links are blue at 400 with no underline (`oklch(0.576 0.251 258)`, the P3 blue-700, and `oklch(0.717 0.165 251)` in dark), and so are fieldset footer links; only a link inside a Note is underlined (2px offset, 500). All 15 blue links in each mode's inventory are bare.
- **Badges**: every badge the pages show is the subtle style: the gray "Not Enabled", "+4" and blue "Current", "Pro", "New", "3 Recommendations", an amber count in the sidebar. "Not Enabled" reads exactly as /geist/badge's gray-subtle (24px, 12px padding, 12/500); "Current" is the small size (20px, 8px padding, 11px). Geist paints the fill on `::before` with `mix-blend-mode`, so the dashboard reads used `box: "::before"`. The pack now reads the subtle pair from the docs page.
- **Cross-checks that agree with the docs readings** (not merged):
  - Fields and selects: the project search's input and the observability select are background-100 (`#fff` / `#0a0a0a`) at 36px with 6px corners and the gray-alpha-400 ring, over the page fill; Members' invite fields are the same.
  - `button.primary` ("Add New") is ink, 36px, 10px padding, 14/500. The icon button and the small secondary are background-100 inside the hairline, as on the docs.
  - `kbd` (the sidebar Find chip) is 20px, 4px corners, 12px, background-100 in the ring, but in gray-1000, not the docs' gray-900.
  - `tooltip` is inverted (`#0a0a0a` / white), 8px corners, 8px padding, 13px. `dialog` (Domains' Add Domain) has 12px corners and the modal shadow; a fieldset footer band closes settings cards.
  - Tabs: Members' Team Members / Pending / Suggested tabs are the docs' tabs exactly (50px, 2px padding, 14/400, a 2px ink bottom border on the current one). A deployment's own nav is a second style: 32px pills, 12px padding, 14/500, the current one on gray-200 (`#ebebeb` / `#1f1f1f`) and the rest in gray-800.
  - Menus: the account menu (a Radix popover, not a Geist menu) has 36px rows with 8px padding and 6px corners, a 12px surface and a deeper drop (8px/16px and 24px/32px layers). The "Add New" Geist menu has 32px rows in two columns, with the docs menu's shadow.
- **Looks the docs don't show**: ⌘K opens the sidebar's Find palette, a 384px panel anchored under the search field over a 60% wash, with 48px two-line rows and a moving gray-alpha-100 highlight; Geist's centered command menu stays the pack's reference. The project list in list view is one `material-small` surface with hairline dividers between rows. The sidebar keeps the 36px rows measured on 2026-10-21; inside Settings it lists sections as text rows, the current one on gray-200.
