```npm

```

## Usage

Use drawers to display content that slides in from the edge of the screen.

```tsx
import { Button } from "@/components/ui/button"
import { Dialog, DialogContent } from "@/components/ui/dialog"
import { Drawer } from "@/components/ui/drawer"
```

```tsx
<Dialog>
  <Button>Open Drawer</Button>
  <Drawer placement="bottom">
    <DialogContent>Drawer content</DialogContent>
  </Drawer>
</Dialog>
```

## Anatomy

A `Drawer` has no built-in trigger. Wrap it in a `Dialog` with a `Button` child as the trigger, and put your content inside `DialogContent`.

```tsx
import { Button } from "@/components/ui/button"
import { Dialog, DialogContent } from "@/components/ui/dialog"
import {
  Drawer,
  DrawerHandle,
  DrawerSwipeArea,
  DrawerProvider,
  DrawerIndent,
  DrawerIndentBackground,
} from "@/components/ui/drawer"
```

```tsx
<Dialog>
  <Button />
  <Drawer>
    <DialogContent>
      <DrawerHandle />
    </DialogContent>
  </Drawer>
</Dialog>
```

`DrawerHandle` is a visible drag affordance. `DrawerSwipeArea` is an edge region that opens the drawer by swiping. `DrawerIndent` and `DrawerIndentBackground` wrap page content that scales and translates behind an open drawer, and `DrawerProvider` scopes visual state explicitly — most apps don't need it.

## Open state

Rendered under a `Dialog`, the drawer shares the dialog's open state, so the trigger `Button` opens it with no wiring. To drive it yourself, pass `isOpen` with `onOpenChange` (or `defaultOpen` for uncontrolled).

```tsx
const [isOpen, setIsOpen] = React.useState(false)

<Drawer isOpen={isOpen} onOpenChange={setIsOpen}>
  <DialogContent>...</DialogContent>
</Drawer>
```

## Dismissal

The drawer dismisses on swipe, outside interaction, and Escape. Disable each with `swipeToDismiss`, `isDismissable`, and `isKeyboardDismissDisabled` respectively.

```tsx
<Drawer swipeToDismiss={false} isDismissable={false} isKeyboardDismissDisabled>
  <DialogContent>...</DialogContent>
</Drawer>
```

## Snap points

`snapPoints` lets a bottom (or top) drawer rest at several heights: fractions of the viewport between 0 and 1, pixel numbers, or `px`/`rem` strings. Give the drawer the height of its largest point; it opens at the first unless `defaultSnapPoint` (or a controlled `snapPoint` with `onSnapPointChange`) says otherwise.

```tsx
<Drawer snapPoints={[0.5, 1]} className="h-[calc(100dvh-3rem)]">
  <DialogContent>...</DialogContent>
</Drawer>
```

## Indent

`DrawerIndent` wraps the page behind the drawers of its `DrawerProvider`. By default it scales back under a sheet; `effect="push"` slides it aside for a side menu, by `--drawer-indent-push`, and fades its content — pair it with `hasBackdrop={false}` on the side drawer so no scrim covers the page too. Set that variable where both the page and the portaled drawer read it, and size the drawer with it. Give sheets their own provider so they don't push the page too.

```tsx
<DrawerProvider>
  <DrawerIndentBackground />
  <DrawerIndent effect="push">
    <DrawerProvider>
      <DrawerIndent>{page}</DrawerIndent>
    </DrawerProvider>
  </DrawerIndent>
</DrawerProvider>
```
