A radar chart wraps a category axis into a circle and draws each series as a closed shape. Reach for it when the reader should judge a _profile_ — the balance across five to eight categories — and compare two of them at a glance. It is a poor tool for reading exact values or for ranking: the eye compares areas, and area grows with the square of the value. When precision matters, use the [bar chart](/docs/components/chart-bar).

`radarChart` builds the chart from your rows and the fields to read; [`Chart`](/docs/components/chart) renders it in your design system.

## Installation

```npm
npx shadcn@latest add @dotui/chart-radar
```

It brings the [`chart`](/docs/components/chart) core along with it.

## Usage

```tsx
import { defineChart } from "@tanstack/charts"

import { Chart } from "@/components/ui/chart"
import { radarChart } from "@/components/ui/chart-radar"
```

Point `x` at the category field and `y` at the value field — one row per category. A chart is a figure, so `ariaLabel` is required.

```tsx
const data = [
  { month: "Jan", desktop: 186 },
  { month: "Feb", desktop: 305 },
  { month: "Mar", desktop: 237 },
]

const chart = defineChart(
  radarChart(data, {
    x: "month",
    y: "desktop",
    labels: { desktop: "Desktop" },
  }),
)

export function Example() {
  return <Chart definition={chart} ariaLabel="Desktop visitors by month" />
}
```

## Data shape

Two shapes work, and both draw the same chart.

**Wide** rows carry one column per series. Pass the columns as an array, and name them with `labels`:

```tsx
radarChart(data, {
  x: "month",
  y: ["desktop", "mobile"],
  labels: { desktop: "Desktop", mobile: "Mobile" },
})
```

**Long** rows carry one row per series per category, with the series key in its own field. Pass that field as `series`; series take colors in the order they first appear, or in the order of the keys you list in `order`:

```tsx
radarChart(data, {
  x: "month",
  y: "visitors",
  series: "device",
  labels: { desktop: "Desktop", mobile: "Mobile" },
})
```

Series take colors from `--chart-1` through `--chart-8` in order. Every series is drawn on one shared radius scale running from zero to the largest value, nicened — `max` pins the outer ring instead. A radar with two units on it is a chart with two meanings, so normalize first.

## Shape

`fill` sets the series fill opacity — `0` draws outlines only. `strokeWidth` sets the outline, `points` adds a dot at every category, and `radiusRatio` sets how much of the available radius the radar fills, leaving room for the labels.

## Grid and labels

The rings, the spokes, and the circumference labels are three separate switches: `grid` draws the rings, `spokes` the lines running out to each category, and `axes` the labels. `gridShape` makes the rings circles instead of polygons, `gridTicks` sets how many there are, and `gridFill` tints the area inside the outer one.

```tsx
radarChart(data, {
  x: "month",
  y: "desktop",
  gridShape: "circle",
  gridFill: 0.2,
  spokes: false,
})
```

`formatX` rewrites the circumference labels and the tooltip title, and `axisDetail` adds a second, muted line above each one — the value at that spoke, a share, a delta. `formatY` formats the tooltip values. `legend` adds a color legend below the radar.

## Composing

A radar draws in polar coordinates, so extra layers go through the `marks` option rather than the chart's top-level marks — they share the radar's angle and radius scales. Wrap a layer in `polarDecorative` to paint it without making it a focus stop or a tooltip row. Here each row also carries a `target`:

```tsx
import { radialLine } from "@tanstack/charts/polar"
import { curveLinearClosed } from "d3-shape"

import { polarDecorative } from "@/components/ui/chart"

const chart = defineChart(
  radarChart(data, {
    x: "month",
    y: "desktop",
    marks: [
      polarDecorative(
        radialLine(data, {
          angle: "month",
          radius: "target",
          curve: curveLinearClosed,
          stroke: "var(--color-fg-muted)",
          strokeDasharray: "4 4",
        }),
      ),
    ],
  }),
)
```

The radius scale only reads the series, so set `max` when a layer reaches past them. HTML — a score in the middle, an icon legend — goes in `Chart`'s children, or beside the chart.

## Accessibility

- `ariaLabel` is required and names the figure; add `ariaDescription` when the takeaway needs a sentence.
- The chart surface is in the tab order. Arrow keys move between spokes, `Home` and `End` jump to the first and last, `Enter` and Space pin the tooltip, and `Escape` dismisses it.
- Hovering or focusing a spoke reports every series at that category, named and valued — color alone never carries the distinction.
