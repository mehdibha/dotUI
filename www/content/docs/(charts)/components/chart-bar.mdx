A bar chart compares values across categories: one bar per category, or one bar per series inside each category band. Bars are read by their length from zero, so the value axis always includes zero — when only the trend over time matters, use the [line chart](/docs/components/chart-line).

Bar charts are [`barY`](https://tanstack.com/charts/latest/docs/reference/marks/bar-and-rect) marks rendered by [`Chart`](/docs/components/chart). Copy an example below and change what you need.

## Installation

```npm
npx shadcn@latest add @dotui/chart
```

## Usage

```tsx
import { defineChart } from "@tanstack/charts"
import { barY } from "@tanstack/charts/bar"
import { scaleLinear } from "@tanstack/charts/scales/linear"

import { Chart, chartBand, chartLook } from "@/components/ui/chart"
```

A band scale holds the categories, a linear scale the values. Point the bar's `x` at the category field and `y` at the value field:

```tsx
const data = [
  { month: "Jan", desktop: 186 },
  { month: "Feb", desktop: 305 },
  { month: "Mar", desktop: 237 },
]

const chart = defineChart({
  scales: {
    x: { scale: chartBand },
    y: {
      scale: scaleLinear,
      nice: true,
      grid: true,
      axis: chartLook.valueAxis,
    },
  },
  marks: [
    barY(data, {
      x: "month",
      y: "desktop",
      z: () => "Desktop",
      radius: chartLook.barRadius,
      maxThickness: chartLook.barMaxThickness,
    }),
  ],
})

export function Example() {
  return <Chart definition={chart} ariaLabel="Desktop visitors per month" />
}
```

`z` names the series in the tooltip. `radius`, `maxThickness`, and the value axis come from [`chartLook`](/docs/components/chart#the-look), so the bars follow your design system — set a number instead to fix one chart's look.

## Several series

Rows with one column per series fold into one row per bar. Give each its display name through `color`; series take colors from `--chart-1` through `--chart-8` in the order they appear:

```tsx
import { group } from "@tanstack/charts/group"
import { fold } from "@tanstack/charts/transform/fold"

const devices = { desktop: "Desktop", mobile: "Mobile" }

const rows = fold(data, {
  fields: ["desktop", "mobile"],
  as: { key: "device", value: "visitors" },
})

barY(rows, {
  x: "month",
  y: "visitors",
  color: (row) => devices[row.device],
  layout: group({ padding: 0.15 }),
})
```

`group()` sets the series side by side in each band. When the category is the series — one colored bar per browser — write the display names in the data and point both `color` and `z` at that field, as in the [Per-category color](#examples) example.

## Stacking

`layout: stack()` stacks the series inside each band, in order; the tooltip still reports each segment's own value. Round only the outer end, so segments meet flush:

```tsx
import { stack } from "@tanstack/charts/stack"

barY(rows, {
  x: "month",
  y: "visitors",
  color: (row) => devices[row.device],
  layout: stack(),
  radius: { end: chartLook.barRadius },
})
```

Positive values stack up from zero and negative values down from it. `stack({ offset: "normalize" })` divides each band by its total for a 100% stack — format the value axis as a percentage.

## Orientation

`barX` puts the categories on the y axis and the values on x, which is what long category names want. Swap the scales, and focus the categories with `focus: "group-y"`:

```tsx
import { barX } from "@tanstack/charts/bar"

const chart = defineChart({
  scales: {
    x: {
      scale: scaleLinear,
      nice: true,
      grid: true,
      axis: chartLook.valueAxis,
    },
    y: { scale: chartBand },
  },
  marks: [barX(data, { x: "desktop", y: "month", z: () => "Desktop" })],
  focus: "group-y",
})
```

## Axes and formatting

Every axis gets the house look: no domain line, no tick marks, labels clear of the plot. `axis: false` hides one; an object shows it, and `ticks.format` formats its labels — and the tooltip values on that axis:

```tsx
y: {
  scale: scaleLinear,
  nice: true,
  grid: true,
  axis: { ticks: { format: (value) => compact.format(Number(value)) } },
}
```

`grid: true` draws your design system's gridlines.

## Annotations

Labels, baselines, and targets are marks too. Wrap them in `decorative` so they paint without becoming focus stops or tooltip rows:

```tsx
import { decorative } from "@tanstack/charts/mark/decorative"
import { ruleY } from "@tanstack/charts/rule"
import { text } from "@tanstack/charts/text"

marks: [
  ruleY([0], { stroke: "var(--color-border)" }),
  barY(data, { x: "month", y: "desktop", z: () => "Desktop" }),
  decorative(
    text(data, { x: "month", y: "desktop", text: "desktop", dy: -10 }),
  ),
]
```

To restyle the bars on focus, give them `states` — the [Highlight on focus](#examples) example dims every bar but the focused one.

## Accessibility

- `ariaLabel` is required and names the figure: describe what the bars measure, not the chart type. Add `ariaDescription` when the takeaway needs a sentence.
- The chart surface is in the tab order. Arrow keys walk the categories, `Home` and `End` jump to the ends, `Enter` and Space pin the tooltip, and `Escape` dismisses it. Focus reads a whole category at once, so a grouped or stacked chart announces every series in the band.
- Color alone never carries the meaning — name every series, and add `chartLegend` when a chart has more than one.
