A radial bar chart trades the precision of a straight axis for a compact, recognizable shape. It reads well for a single value against a target — a gauge — and for a handful of categories where the ranking matters more than the exact gap. Past five or six rings, or when the values must be compared closely, use the [bar chart](/docs/components/chart-bar).

Radial bar charts are [`radialBarAngle`](https://tanstack.com/charts/latest/docs/reference/marks/polar) marks inside `polar()`, rendered by [`Chart`](/docs/components/chart). Copy an example below and change what you need.

## Installation

```npm
npx shadcn@latest add @dotui/chart
```

## Usage

```tsx
import { defineChart } from "@tanstack/charts"
import { polar, radialBarAngle } from "@tanstack/charts/polar"
import { scaleBand } from "@tanstack/charts/scales/band"
import { scaleLinear } from "@tanstack/charts/scales/linear"

import {
  Chart,
  chartLook,
  chartSliceTooltip,
  polarDecorative,
} from "@/components/ui/chart"
```

One row per ring, drawn from the inside out. A linear scale turns values into angles, and a band scale gives each ring its slice of the radius:

```tsx
const data = [
  { browser: "Chrome", visitors: 275 },
  { browser: "Safari", visitors: 200 },
  { browser: "Firefox", visitors: 187 },
]

const max = Math.max(...data.map((row) => row.visitors))

const chart = defineChart({
  scales: { x: null, y: null },
  marks: [
    polar({
      scales: {
        angle: { scale: scaleLinear().domain([0, max]) },
        radius: {
          scale: () => scaleBand().paddingInner(0.2),
          range: [({ radius }) => radius * 0.3, ({ radius }) => radius],
        },
      },
      radiusRatio: 0.95,
      marks: [
        polarDecorative(
          radialBarAngle(data, {
            angle: () => max,
            radius: "browser",
            fill: "var(--color-muted)",
            motion: false,
          }),
        ),
        radialBarAngle(data, {
          angle: "visitors",
          radius: "browser",
          color: "browser",
          cornerRadius: chartLook.barRadius,
        }),
      ],
    }),
  ],
  focus: "nearest",
  tooltip: chartSliceTooltip("browser", "visitors"),
})

export function Example() {
  return <Chart definition={chart} ariaLabel="Visitors by browser" />
}
```

Without x and y scales the chart is square. A ring's x and y are its angle and radius: `focus: "nearest"` focuses the ring under the pointer, and `chartSliceTooltip` names and values it from its own fields. Rings take colors from `--chart-1` through `--chart-8` in data order.

`cornerRadius` comes from [`chartLook`](/docs/components/chart#the-look), so the arc ends follow your design system — set a number instead to fix one chart's look.

## Geometry

Angles are radians, clockwise from twelve o'clock. `startAngle` and `endAngle` set the sweep. The radius `range` sets where the rings start and end, as callbacks of the circle's radius, so a chart keeps its proportions at any size. `radiusRatio` leaves room around the whole circle:

```tsx
polar({
  scales: {
    angle: { scale: scaleLinear().domain([0, 1600]) },
    radius: {
      scale: () => scaleBand().paddingInner(0.2),
      range: [({ radius }) => radius * 0.78, ({ radius }) => radius * 0.95],
    },
  },
  endAngle: (250 * Math.PI) / 180,
  radiusRatio: 0.9,
  marks: [
    /* … */
  ],
})
```

`paddingInner` sets the gap between rings, as a share of the space each ring gets.

## Targets and tracks

The angle scale's domain is the value that fills the whole sweep. Give a gauge its target there, so the arc reads as a share of it, and draw the unfilled remainder as a second ring reaching the target. Wrap that track in `polarDecorative` so it paints without becoming a focus stop:

```tsx
const data = [{ browser: "Safari", visitors: 1260 }]

const max = 1600

marks: [
  polarDecorative(
    radialBarAngle(data, {
      angle: () => max,
      radius: "browser",
      fill: "var(--color-muted)",
      motion: false,
    }),
  ),
  radialBarAngle(data, {
    angle: "visitors",
    radius: "browser",
    color: "browser",
    cornerRadius: "full",
  }),
]
```

`cornerRadius: "full"` rounds the arc ends into pills. With a plain `scaleLinear` as the angle scale, the largest value fills the sweep.

## Stacking

To lay one row's values end to end around a single ring, fold the series into one row per segment, then `stackRowsX` works out where each starts and ends. It is the radial equivalent of a stacked bar: the ring is the whole, the arcs are the parts.

```tsx
import { fold } from "@tanstack/charts/transform/fold"
import { stackRowsX } from "@tanstack/charts/transform/stack"

const data = [{ month: "january", desktop: 1260, mobile: 570 }]

const devices = { desktop: "Desktop", mobile: "Mobile" }

const rows = stackRowsX(
  fold(data, {
    fields: ["desktop", "mobile"],
    as: { key: "device", value: "visitors" },
  }),
  {
    x: "visitors",
    y: "month",
    z: (row: { device: keyof typeof devices }) => devices[row.device],
  },
)

radialBarAngle(rows, {
  angle1: "x1",
  angle2: "x2",
  radius: "month",
  color: "z",
  cornerRadius: 5,
})
```

`z` carries each segment's display name, so the tooltip reads it with `chartSliceTooltip("z", "visitors")`. A plain `scaleBand` keeps the one ring at full thickness.

## Labels and grid

Ring names are `radialText` marks at angle zero, where every ring starts. Text takes a numeric radius, so leave `radius` off the rings, which then sit at their row index, and place each name at the same index:

```tsx
import { radialText } from "@tanstack/charts/polar"

marks: [
  radialBarAngle(data, {
    angle: "visitors",
    color: "browser",
    cornerRadius: chartLook.barRadius,
  }),
  polarDecorative(
    radialText(data, {
      angle: 0,
      radius: (_row, { index }) => index,
      text: "browser",
      anchor: "start",
      dx: 8,
      fill: "var(--color-fg)",
      fontSize: 11,
    }),
  ),
]
```

`radialGrid` draws concentric gridlines behind the rings. Give it its own radius scale, from the center to the edge, so the lines step through the whole circle rather than the rings:

```tsx
import { radialGrid } from "@tanstack/charts/polar"

polar({
  scales: {
    angle: { scale: scaleLinear },
    radius: {
      /* … */
    },
    grid: {
      channel: "radius",
      scale: scaleLinear().domain([0, 1]),
      range: [0, ({ radius }) => radius],
    },
  },
  guides: [
    radialGrid({
      scale: "grid",
      strokeDasharray: chartLook.grid.strokeDasharray,
    }),
  ],
  marks: [
    /* … */
  ],
})
```

`color: { legend: chartLegend }` names the rings below the chart, or wherever your design system puts legends.

## Center label

The middle of a ring is the place for the number it summarizes. `Chart` children render as an HTML overlay covering the chart and ignoring the pointer. Center the label with flex, and it uses your real typography while staying out of the keyboard path.

```tsx
<Chart definition={chart} ariaLabel="Safari visitors as a progress ring">
  <div className="flex h-full flex-col items-center justify-center">
    <span className="text-2xl font-bold">1,260</span>
    <span className="text-sm text-fg-muted">Visitors</span>
  </div>
</Chart>
```

## Accessibility

- `ariaLabel` is required and names the figure; add `ariaDescription` when the takeaway needs a sentence.
- The chart surface is in the tab order. Arrow keys move between arcs, `Home` and `End` jump to the first and last, `Enter` and Space pin the tooltip, and `Escape` dismisses it.
- Color alone never carries the distinction — name every ring in the data, so `chartSliceTooltip` and `chartLegend` read it, and print the names on the arcs with `radialText`.
- A ring's angle is harder to compare than a bar's length. Print the numbers when the exact values matter.
