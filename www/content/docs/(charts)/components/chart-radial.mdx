A radial bar chart trades the precision of a straight axis for a compact, recognizable shape. It reads well for a single value against a target — a gauge — and for a handful of categories where the ranking matters more than the exact gap. Past five or six rings, or when the values must be compared closely, use the [bar chart](/docs/components/chart-bar).

`radialChart` builds the chart from your rows, the field holding each value, and the field naming each ring; [`Chart`](/docs/components/chart) renders it in your design system.

## Installation

```npm
npx shadcn@latest add @dotui/chart-radial
```

It brings the [`chart`](/docs/components/chart) core along with it.

## Usage

```tsx
import { defineChart } from "@tanstack/charts"

import { Chart } from "@/components/ui/chart"
import { radialChart } from "@/components/ui/chart-radial"
```

Each row becomes one ring, drawn from the inside out. A chart is a figure, so `ariaLabel` is required.

```tsx
const data = [
  { browser: "chrome", visitors: 275 },
  { browser: "safari", visitors: 200 },
  { browser: "firefox", visitors: 187 },
]

const chart = defineChart(
  radialChart(data, {
    value: "visitors",
    name: "browser",
    labels: { chrome: "Chrome", safari: "Safari", firefox: "Firefox" },
    track: true,
  }),
)

export function Example() {
  return <Chart definition={chart} ariaLabel="Visitors by browser" />
}
```

## Geometry

Angles are radians, clockwise from twelve o'clock; radii are shares of the circle the chart resolves for its box, so a chart keeps its proportions at any size.

```tsx
radialChart(data, {
  value: "score",
  name: "team",
  startAngle: -Math.PI / 2,
  endAngle: Math.PI / 2,
  innerRadius: 0.7,
  outerRadius: 0.98,
  radiusRatio: 0.9,
})
```

`max` sets the value that fills the whole sweep — without it the largest value fills it. Give a gauge an explicit `max` so the arc reads as a share of a target, and turn on `track` to draw the unfilled remainder. `cornerRadius` rounds the arc ends; a large value gives pills.

## Stacking

Pass an array of fields as `value` to stack one row's values into a single ring, laid end to end from `startAngle`. It is the radial equivalent of a stacked bar: the ring is the whole, the arcs are the parts.

```tsx
radialChart([{ month: "january", desktop: 1260, mobile: 570 }], {
  value: ["desktop", "mobile"],
  name: "month",
  labels: { desktop: "Desktop", mobile: "Mobile" },
  max: 2200,
})
```

Without `max`, the stack's total fills the sweep.

## Labels and grid

`barLabels` prints each ring's name at the start of its arc — start the sweep at twelve o'clock so the names stack down the rings. `grid` draws concentric gridlines behind them, and `legend` adds a color legend. `formatValue` formats the values in the tooltip.

## Center label

The middle of a ring is the place for the number it summarizes. `Chart` children render as an HTML overlay covering the chart and ignoring the pointer — center the label with flex, and it uses your real typography while staying out of the keyboard path.

```tsx
<Chart definition={chart} ariaLabel="Safari visitors as a progress ring">
  <div className="flex h-full flex-col items-center justify-center">
    <span className="text-2xl font-bold">1,260</span>
    <span className="text-sm text-fg-muted">Visitors</span>
  </div>
</Chart>
```

## Composing

`marks` takes more [TanStack Charts](https://tanstack.com/charts) polar marks, drawn over the rings inside the circle's own transform — cartesian marks would land outside it. They share the chart's scales: an angle is a value, and a radius is a ring's name (its display name, when you pass `labels`). Wrap a mark in `polarDecorative` to keep it out of focus and the tooltip.

```tsx
import { radialBarAngle } from "@tanstack/charts/polar"

import { polarDecorative } from "@/components/ui/chart"

const data = [
  { browser: "Chrome", visitors: 275, goal: 300 },
  { browser: "Safari", visitors: 200, goal: 180 },
  { browser: "Firefox", visitors: 187, goal: 220 },
]

const chart = defineChart(
  radialChart(data, {
    value: "visitors",
    name: "browser",
    max: 320,
    marks: [
      polarDecorative(
        radialBarAngle(data, {
          angle: "goal",
          radius: "browser",
          fill: "none",
          stroke: "var(--color-fg-muted)",
          strokeDasharray: "3 3",
          cornerRadius: 4,
        }),
      ),
    ],
  }),
)
```

`radialChart` returns a plain spec, so the rest of the definition is yours too — spread it and override `tooltip`, `focus`, or `motion`:

```tsx
const chart = defineChart({ ...radialChart(data, options), motion: false })
```

## Accessibility

- `ariaLabel` is required and names the figure; add `ariaDescription` when the takeaway needs a sentence.
- The chart surface is in the tab order. Arrow keys move between arcs, `Home` and `End` jump to the first and last, `Enter` and Space pin the tooltip, and `Escape` dismisses it.
- Color alone never carries the distinction — the tooltip and the legend name every ring, and `barLabels` prints the names on the arcs themselves.
- A ring's angle is harder to compare than a bar's length. Print the numbers when the exact values matter.
