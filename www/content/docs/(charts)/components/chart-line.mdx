A line chart answers how a value changes across an ordered domain — months, days, versions. Reach for it when the trend is the point; when the area under the line carries meaning too, use the [area chart](/docs/components/chart-area).

Line charts are [`lineY`](https://tanstack.com/charts/latest/docs/reference/marks/line-and-area) marks rendered by [`Chart`](/docs/components/chart). Copy an example below and change what you need.

## Installation

```npm
npx shadcn@latest add @dotui/chart
```

## Usage

```tsx
import { defineChart } from "@tanstack/charts"
import { lineY } from "@tanstack/charts/line"
import { scaleLinear } from "@tanstack/charts/scales/linear"
import { scalePoint } from "@tanstack/charts/scales/point"

import { Chart, chartLook } from "@/components/ui/chart"
```

A point scale holds the categories, a linear scale the values. Point the line's `x` at the category field and `y` at the value field:

```tsx
const data = [
  { month: "Jan", desktop: 186 },
  { month: "Feb", desktop: 305 },
  { month: "Mar", desktop: 237 },
]

const chart = defineChart({
  scales: {
    x: { scale: scalePoint },
    y: {
      scale: scaleLinear,
      nice: true,
      grid: true,
      axis: chartLook.valueAxis,
    },
  },
  marks: [
    lineY(data, {
      x: "month",
      y: "desktop",
      z: () => "Desktop",
      curve: chartLook.curve,
      strokeWidth: chartLook.strokeWidth,
    }),
  ],
})

export function Example() {
  return <Chart definition={chart} ariaLabel="Desktop visitors by month" />
}
```

`z` names the series in the tooltip. `curve`, `strokeWidth`, and the value axis come from [`chartLook`](/docs/components/chart#the-look), so the line follows your design system — set a value instead to fix one chart's look.

## Several series

Rows with one column per series fold into one row per point. Give each its display name through `color`, which also draws one line per series; series take colors from `--chart-1` through `--chart-8` in the order they appear:

```tsx
import { fold } from "@tanstack/charts/transform/fold"

const devices = { desktop: "Desktop", mobile: "Mobile" }

const rows = fold(data, {
  fields: ["desktop", "mobile"],
  as: { key: "device", value: "visitors" },
})

lineY(rows, {
  x: "month",
  y: "visitors",
  color: (row) => devices[row.device],
  curve: chartLook.curve,
  strokeWidth: chartLook.strokeWidth,
})
```

Rows that already name their series in a field need no fold: write the display names in the data and point `color` at that field. Add `color: { legend: chartLegend }` to the definition for a color legend, placed where your design system puts it.

## Curves and points

`chartLook.curve` follows your design system. To fix one chart's curve, pick it from `chartCurves`: `natural`, `monotone`, `linear`, or `step`. `points: true` draws a dot at every point:

```tsx
import { Chart, chartCurves, chartLook } from "@/components/ui/chart"

lineY(data, {
  x: "month",
  y: "desktop",
  z: () => "Desktop",
  curve: chartCurves.step,
  strokeWidth: chartLook.strokeWidth,
  points: true,
})
```

Interpolation only changes how the line travels between observations. It does not smooth the data or claim anything about the values in between. A `null` value is a gap, not a zero: the line stops and restarts on the far side. The line follows the rows in the order you pass them, so sort them by `x` first.

## Time

When `x` holds `Date`s, put it on a time scale. `scaleUtc` from `d3-scale` comes with the chart; `nice` rounds the ends to tidy dates:

```tsx
import { scaleUtc } from "d3-scale"

x: {
  scale: scaleUtc,
  nice: true,
  axis: { ticks: { format: (value) => day.format(value as Date) } },
}
```

## Axes and formatting

Every axis gets the house look: no domain line, no tick marks, labels clear of the plot. `axis: false` hides one; an object shows it, and `ticks.format` formats its labels — and the tooltip values on that axis:

```tsx
scales: {
  x: {
    scale: scalePoint,
    axis: { ticks: { format: (value) => String(value).slice(0, 3) } },
  },
  y: {
    scale: scaleLinear,
    nice: true,
    grid: true,
    axis: { ticks: { format: (value) => compact.format(Number(value)) } },
  },
}
```

`grid: true` draws your design system's gridlines.

## Annotations

Labels, markers, and custom dots are marks too. Wrap them in `decorative` so they paint without becoming focus stops or tooltip rows; the line keeps both:

```tsx
import { decorative } from "@tanstack/charts/mark/decorative"
import { text } from "@tanstack/charts/text"

marks: [
  lineY(data, { x: "month", y: "desktop", z: () => "Desktop", points: true }),
  decorative(
    text(data, { x: "month", y: "desktop", text: "desktop", dy: -12 }),
  ),
]
```

A marker that stands in for the line's own point can join the line's focus group instead: give it the line's series name as `z`, as in the [Dot Colors](#examples) example.

A line is a mark like any other, so it draws inside any chart — over bars, or on a second axis, as in the [`Chart`](/docs/components/chart) example.

## Accessibility

- `ariaLabel` is required and names the figure; add `ariaDescription` when the takeaway needs a sentence.
- The chart surface is in the tab order. Arrow keys move between points, `Home` and `End` jump to the first and last, `Enter` and Space pin the tooltip, and `Escape` dismisses it. Focus reads every series at that position at once.
- Color alone never carries the distinction — name every series, and add `chartLegend` when a chart has more than one.
- When exact values matter, put a real table or a short summary next to the chart — HTML the reader can select, translate, and print.
