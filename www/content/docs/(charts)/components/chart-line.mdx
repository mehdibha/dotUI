A line chart answers how a value changes across an ordered domain — months, days, versions. Reach for it when the trend is the point; when the area under the line carries meaning too, use the [area chart](/docs/components/chart-area).

`lineChart` builds the chart from your rows and the fields to read; [`Chart`](/docs/components/chart) renders it in your design system.

## Installation

```npm
npx shadcn@latest add @dotui/chart-line
```

It brings the [`chart`](/docs/components/chart) core along with it.

## Usage

```tsx
import { defineChart } from "@tanstack/charts"

import { Chart } from "@/components/ui/chart"
import { lineChart } from "@/components/ui/chart-line"
```

Point `x` at the category or time field and `y` at the value field. A chart is a figure, so `ariaLabel` is required.

```tsx
const data = [
  { month: "Jan", desktop: 186 },
  { month: "Feb", desktop: 305 },
  { month: "Mar", desktop: 237 },
]

const chart = defineChart(
  lineChart(data, { x: "month", y: "desktop", labels: { desktop: "Desktop" } }),
)

export function Example() {
  return <Chart definition={chart} ariaLabel="Desktop visitors by month" />
}
```

## Data shape

Two shapes work, and both draw the same chart.

**Wide** rows carry one column per series. Pass the columns as an array, and name them with `labels`:

```tsx
lineChart(data, {
  x: "month",
  y: ["desktop", "mobile"],
  labels: { desktop: "Desktop", mobile: "Mobile" },
})
```

**Long** rows carry one row per series per x value, with the series key in its own field. Pass that field as `series`:

```tsx
lineChart(data, {
  x: "month",
  y: "visitors",
  series: "device",
  labels: { desktop: "Desktop", mobile: "Mobile" },
})
```

Series take colors from `--chart-1` through `--chart-8` in the order they first appear. `order` lists series keys to lead it — the legend and the tooltip follow:

```tsx
lineChart(data, {
  x: "month",
  y: "visitors",
  series: "device",
  order: ["mobile", "desktop"],
})
```

When `x` holds `Date`s, the axis is a time scale.

## Shape

`curve` sets the path between points: `natural` (the default), `monotone`, `linear`, or `step`. `strokeWidth` and `strokeDasharray` set the stroke, and `points` draws a dot at every point.

Interpolation only changes how the line travels between observations — it does not smooth the data or claim anything about the values in between. A `null` value is a gap, not a zero: the line stops and restarts on the far side.

## Axes and formatting

`axes` shows the x axis (the default), both, the y axis, or neither; `grid: false` drops the gridlines and `legend` adds a color legend. `formatX` and `formatY` format the ticks — and the tooltip, which reads values the way the axes print them.

## Composing

`lineChart` returns a plain spec, so you extend it like any TanStack Charts definition. Labels, reference rules, and custom dots are marks straight from `@tanstack/charts`, on the same scales:

```tsx
import { decorative } from "@tanstack/charts/mark/decorative"
import { text } from "@tanstack/charts/text"

const lines = lineChart(data, { x: "month", y: "desktop", points: true })

const chart = defineChart({
  ...lines,
  marks: [
    ...lines.marks,
    decorative(
      text(data, { x: "month", y: "desktop", text: "desktop", dy: -12 }),
    ),
  ],
})
```

Wrap an annotation in `decorative` so it paints without becoming a focus stop — the line's points keep the keyboard stops and the tooltip rows. A marker that stands in for the line's own point, like a dot colored per category, can instead join the line's focus group: give it a `z` of the series' display name.

`lineSeries` returns just the line mark, to draw lines inside any chart — over bars, or on a second axis.

## Accessibility

- `ariaLabel` is required and names the figure; add `ariaDescription` when the takeaway needs a sentence.
- The chart surface is in the tab order. Arrow keys move between points, `Home` and `End` jump to the first and last, `Enter` and Space pin the tooltip, and `Escape` dismisses it.
- Color alone never carries the distinction — the legend, tooltip, and axis labels all name the series.
- When exact values matter, put a real table or a short summary next to the chart — HTML the reader can select, translate, and print.
