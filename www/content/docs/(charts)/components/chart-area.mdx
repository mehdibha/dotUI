An area chart is a line chart whose fill carries meaning: distance from a baseline, or the span between two boundaries. Reach for it when the reader should compare magnitude or composition — not just because a filled chart looks stronger. When only the trend matters, use the [line chart](/docs/components/chart-line).

`areaChart` builds the chart from your rows and the fields to read; [`Chart`](/docs/components/chart) renders it in your design system.

## Installation

```npm
npx shadcn@latest add @dotui/chart-area
```

It brings the [`chart`](/docs/components/chart) core along with it.

## Usage

```tsx
import { defineChart } from "@tanstack/charts"

import { Chart } from "@/components/ui/chart"
import { areaChart } from "@/components/ui/chart-area"
```

Point `x` at the category or time field and `y` at the value field. A chart is a figure, so `ariaLabel` is required.

```tsx
const data = [
  { month: "Jan", desktop: 186 },
  { month: "Feb", desktop: 305 },
  { month: "Mar", desktop: 237 },
]

const chart = defineChart(
  areaChart(data, { x: "month", y: "desktop", labels: { desktop: "Desktop" } }),
)

export function Example() {
  return <Chart definition={chart} ariaLabel="Desktop visitors by month" />
}
```

## Data shape

Two shapes work, and both draw the same chart.

**Wide** rows carry one column per series. Pass the columns as an array, and name them with `labels`:

```tsx
areaChart(data, {
  x: "month",
  y: ["desktop", "mobile"],
  labels: { desktop: "Desktop", mobile: "Mobile" },
})
```

**Long** rows carry one row per series per x value, with the series key in its own field. Pass that field as `series`; series take colors in the order they first appear, or in the order of the keys you list in `order`:

```tsx
areaChart(data, {
  x: "month",
  y: "visitors",
  series: "channel",
  labels: { organic_search: "Organic search", paid_social: "Paid social" },
})
```

Series take colors from `--chart-1` through `--chart-8` in order. A `null` value leaves a gap rather than dropping to zero. When `x` holds `Date`s, the axis is a time scale.

## Stacking

`stacked` stacks the series on one another, in order; the tooltip still reports each band's own value.

```tsx
areaChart(data, {
  x: "month",
  y: ["desktop", "mobile", "other"],
  stacked: true,
})
```

Positive values stack up from zero and negative values down from it, so a mixed-sign group never overlaps itself. `stacked: "normalize"` divides each band by its own x-group total for a 100% stack — format the value axis as a percentage with `formatY`.

## Shape

`curve` sets the interpolation: `natural` (the default), `monotone`, `linear`, or `step`. `fill` takes an opacity, or `"gradient"` for a fade toward the baseline. `strokeWidth` and `points` control the upper edge.

Interpolation only changes the path drawn between observations. It does not smooth the data or create evidence between samples.

## Axes and formatting

`axes` shows the x axis (the default), both, the y axis, or neither; `grid: false` drops the gridlines and `legend` adds a color legend — `legend: "toggle"` lets readers click a series to hide it and hover one to dim the rest. `formatX` and `formatY` format the ticks — and the tooltip, which reads values the way the axes print them.

## Composing

`areaChart` returns a plain spec, so you extend it like any TanStack Charts definition — add a target rule, a highlighted band, or end labels:

```tsx
import { ruleY } from "@tanstack/charts/rule"

const areas = areaChart(data, { x: "month", y: "desktop" })

const chart = defineChart({
  ...areas,
  marks: [...areas.marks, ruleY([200], { strokeDasharray: "4 4" })],
})
```

`areaSeries` returns just the marks — the fill and its edge — to draw areas inside any chart. With `fill: "gradient"`, add `areaGradients(seriesCount)` to the chart's `gradients`.

## Accessibility

- `ariaLabel` is required and names the figure; add `ariaDescription` when the takeaway needs a sentence.
- The chart surface is in the tab order. Arrow keys move between points, `Home` and `End` jump to the first and last, `Enter` and Space pin the tooltip, and `Escape` dismisses it.
- Color alone never carries the distinction — the legend, tooltip, and axis labels all name the series.
