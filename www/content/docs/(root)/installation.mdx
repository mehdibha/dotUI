## Use dotUI Studio

dotUI starts in the [Studio](/studio): compose your design system — colors, typography, icons, density, radius, per-component styles — and preview every change on live components. The export dialog gives you the setup command with your theme baked in, and every component you then add with the shadcn CLI installs pre-styled to your system. Requires [React 19](https://react.dev), [Tailwind CSS 4](https://tailwindcss.com), and [TypeScript 5](https://www.typescriptlang.org).
