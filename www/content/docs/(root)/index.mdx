## Build it in the studio

The studio shows a panel of settings next to a live preview. The preview shows every component and full pages, like a dashboard, a settings screen, a mail app and a checkout, in light and dark mode.

Change a setting and every component follows:

- Pick a brand color. dotUI generates the full palette for light and dark mode.
- Choose fonts for headings, body text and code.
- Pick an icon set: Lucide, Phosphor, Tabler, Remix or Hugeicons.
- Set the corner radius and the density: Compact, Default or Comfortable.
- Style each group of components. For example, make buttons flat, outlined or raised, and inputs outlined or filled.

The studio opens on the Origin preset. You can start from another preset instead, and save your own systems in your browser.

## Put it in your project

When you're ready, click **Export**. You get a shadcn CLI command with your design system in it. Run it in your project, then add the components you need. For a new project, you can also open your system in v0.

What ends up in your project:

- Each component as a plain React file. Read it and edit it like the rest of your code.
- Your colors and radius as CSS variables in your stylesheet, for light and dark mode.
- Your fonts, set up for your framework.

There is no dotUI package to install or update. Components are built on React Aria Components, which handles keyboard navigation, focus and screen readers. Styles use Tailwind CSS 4 and tailwind-variants.
